# THINK FORGE — Sound Assets Directory

This folder contains the audio assets for **THINK FORGE: SYNTAX SCRAMBLE**.

## Included Audio Files:
- `click.wav` — Snappy cyber click for button presses and line selections.
- `type.wav` — Soft mechanical typewriter sound for team name welcome reveal.
- `flash.wav` — Warm atmospheric low-frequency swell for the warm flash transition.
- `unlock.wav` — Mechanical ratcheting dials and heavy latch slide for vault decryption.
- `success.wav` — Harmonious major chord chime when code logic is verified.
- `error.wav` — Subdued coral red buzzer when an attempt is incorrect.
- `ambient.wav` / `ambient.mp3` — Ambient binaural space drone loop.

## Automatic Web Audio API Fallback:
Even if local sound files are deleted, missing, or blocked by browser security restrictions, the built-in procedural Web Audio API synthesizer in `script.js` will seamlessly generate real-time synthetic tones and sound effects with zero dependencies.
